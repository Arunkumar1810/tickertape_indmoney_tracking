# principle-defensive-criteria

Tests 7 classical criteria for defensive investors:
1. Adequate enterprise size
2. Current ratio $\ge 1.5\times$
3. Long-term debt backed by net current assets
4. Uninterrupted positive earnings
5. Reasonable P/E ($\le 25\times$)
6. Graham P/E $\times$ P/B product ($\le 45$)
7. Positive shareholder equity
